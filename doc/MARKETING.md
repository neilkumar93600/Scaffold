## 1. Positioning

### 1.1 Positioning Statement

**For** indie hackers, solo founders, and small startup teams
**who** waste days on repetitive project setup,
**Scaffold** is the developer Launch OS
**that** saves your stack, playbooks, and boilerplates — so you ship faster, every time.
**Unlike** static starter kits and scattered Notion docs,
**Scaffold** is stateful — it learns your preferences once and applies them to every project automatically.

### 1.2 Category
**Developer Launch OS** — a new category. Not a template library. Not a project management tool. Not a code generator.

### 1.3 Positioning Map

```
                  Personalized / Stateful
                           │
              SCAFFOLD ────┤
                           │
  Task-specific ───────────┼─────────────────── Lifecycle
  (one workflow)           │                  (full journey)
                           │
    GitHub Gists           │      Notion / Confluence
    create-next-app        │      Linear / Jira
                           │
                  Generic / Static
```

- **Pain:** "I've set up Stripe 8 times. I still Google the webhook setup every time."

## 6. Copy Guidelines

### 6.1 Voice
- **Direct** — no filler words, no hedging
- **Technical but human** — assumes developer fluency, not corporate formality
- **Confident** — "You'll save 4 hours" not "You might save some time"
- **Empathetic** — acknowledges the pain specifically, not generically

### 6.2 Words to Use
setup loop · launch OS · stack memory · boilerplate · shipped · zero-to-ready · your stack · never again

### 6.3 Words to Avoid
innovative · revolutionize · game-changing · seamless · robust · leveraging · synergies · empower

### 6.4 Headline Formula
**[Pain] + [Scaffold fixes it]**
- "Stop Googling the same Stripe setup. Copy it in one click."
- "New project. Same setup. Until now."
- "Your stack, remembered. Your playbook, ready."
